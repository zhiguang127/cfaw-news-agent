# 数据来源、权限与本地开发隐私说明

| 域名 | 请求 | 用途 |
| --- | --- | --- |
| `www.apple.com` | `https://www.apple.com/newsroom/rss-feed.rss` | Apple 官方公司公告 / Newsroom Atom |
| `blogs.nvidia.com` | `https://blogs.nvidia.com/feed/` | NVIDIA 官方科技博客 RSS |

无需 API key。每次打开或主动刷新各发一次 GET；单源 18 秒应用超时，最多读取 10 条。应用内已观察到 HTTP 200 和解析成功；这不保证未来来源可用、不代表全文或所有事实已核验。来源可更新、下线或返回旧条目；抓取时间只是本次接收时间。没有网页抓取代理。

Apple 当前 feed 只有 Atom `updated`，不能宣称是首次发布时间。应用兼容 CDATA 日期后，单列来源更新时间，发布时间显示“未提供 / 未能解析”。NVIDIA 使用 `pubDate`。宿主格式化时区由宿主决定，参考 card-host 本次为 UTC；本地记录保留 Unix 时间。

界面为中文，原始标题/摘要保留来源语言。摘要直接来自源；没有自动翻译或模型改写。来源链接必须是上述两个 HTTPS 域名，否则过滤。仅展示和可选择复制 URL，没有申请任意网页访问权限；复制由用户的原生文本控件操作完成，不调用脚本 clipboard 服务。

## manifest 权限

- `net`：仅以上两个主机的 RSS 请求，无通配符、图片 CDN 或后台定时请求。
- `storage`：关注记录和已有分析；应用配额 2 MiB，每个保存文件主动限制 220 KB；最多 30 条。
- `octos.turn.start`：只在用户点击时发送所选条目的标题、来源、链接、发布/更新时间、抓取时间、摘要和演示标记。
- `octos.turn.interrupt`：用户取消或分析超时后请求中断。

没有 Matrix、剪贴板、任意 Web、位置、摄像头、消息发送或系统应用权限。没有 `agent` profile 或自定义工具。宿主按标准合同为 bundle 资源添加的回环资产 origin 不等于应用额外的外部请求域名。

## Agent 与不可信新闻

Rinx 将请求交给宿主配置的 Octos / 模型服务；模型提供方和 Octos 可能按其配置保留请求、对话或工具记录。应用无法代替其隐私政策，不接触 API key。本应用不保证删除关注会删除模型方的历史数据。

提示词将新闻 JSON 明确标为不可信数据，要求忽略其中指令、只分析当前条目、不使用工具、不执行代码/交易/消息、区分事实与条件性推断。要求五段式结果，不生成价格目标、概率或买卖指令。当前公共 API 只有 `{text}`，没有独立 system/input 安全边界或 per-turn tool deny 字段；这些约束是提示词要求，不是模型输出已形式化验证的保证。任何实际工具批准仍由 Rinx 原生界面交给用户。不会伪造来源核验。

只保存完整返回的非空文本；空回答、错误、取消和过期回调不会作为新分析保存。已有分析在重试失败时仍保留，并带原分析时间。网络响应、模型文本都不作为 Splash 代码或 HTML 执行。

## 演示与测试

“演示数据”含两条虚构事件，原始主页只用于示范 URL，不是证据；明确显示“不是实时新闻”。点击演示不会抹去最近一次联网状态。对演示点击分析仍调用真实 Octos，并带 `demo:true`。

`tests/fixtures/` 是测试样本；临时 `build/ui-tests/` 可替换网络和 Agent 传输，仅验证失败/成功/取消状态机。它们不随包交付，不是联网记录或真实模型回答。生产包没有测试传输开关。

应用没有遥测或应用自有服务器；来源服务器可看到正常请求的网络信息。联网、模型和宿主行为以各自配置为准。
