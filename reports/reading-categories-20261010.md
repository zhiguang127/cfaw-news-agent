# 阅读分类调整（2026-10-10）

首页分类为全部、AI、数码、效率、科学、产业、生活。旧入口混合了主题（科技、AI）、地域（国际）与商业领域（财经），且把整家媒体绑定到一个类别：MIT所有研究归AI，少数派所有文章归科技，NASA和Popular Science缺少专门入口。

| 阅读主题 | 主要内容 |
| --- | --- |
| AI | 模型、智能体、机器学习和AI进展 |
| 数码 | 手机、电脑、硬件、设备评测与游戏 |
| 效率 | 软件、开发工具、浏览器、笔记工具与工作流 |
| 科学 | 科研、实验、航天与科学探索 |
| 产业 | 企业、融资、财报、商业变化与监管 |
| 生活 | 隐私、订阅权益、健康、环境和出行 |

规则根据每篇标题和来源摘要匹配，可交叉归类；没有线索才参考来源默认方向。新闻卡最多展示两个主题，主题图标同步。筛选显示当前条数/总条数，空分类提示可切换栏目。窄屏分类栏可横向滚动。

分类不调用模型、不自动读取全文。规则及回退集中在 `src/data/retrieval/categories.splash`，不能保证语义分类完全准确，不等同于Agent的影响判断。派生缓存按标题、摘要、来源及旧类别变化失效；最多600份，不写持久记录。准备阶段按4条/8ms分片，避免满容量筛选超过原生64ms预算；快速切换用generation拒绝旧筛选结果。旧用户关注、收藏、日程、来源选择及Agent类别语义保留。

## 本轮验证

- `scripts/test_browse_categories.py`：14项语义与兼容断言通过，六个原生分类按钮点击后显示预期集合。涵盖同来源多主题、AI笔记本交叉归类、AirPods不误判为AI、关键词与分类组合、内容改变后的缓存失效、来源回退及旧财经分类兼容。
- 430×860原生界面：240条明确标注的合成容量新闻，六个类别各40条，筛选通过，无宿主错误。分类标签实际可见，人工检查数码页截图。
- `--ui-size 360x860`：六个按钮可通过窄屏滚动到达，240条容量筛选及AI→生活快速切换通过，无宿主错误。人工检查生活页截图。
- `scripts/test_news_pagination.py`：81条合成新闻仍为40/40/1页，前进、返回通过，无宿主错误。
- 5项组装检查通过，`git diff --check`无空白错误；ZIP CRC及所有bundle文件字节匹配。

以上分类和容量证据来自隔离、合成输入，不代表每条真实新闻的人工语义验收。本轮没有调用模型、修改用户文件或发布到App Hub。
