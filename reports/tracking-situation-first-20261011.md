# 关注动态：先新闻与现状，再建议

用户案例：漫步者新品与产品动向跟踪。原页面先给下一步，把当前情况藏在折叠区；unchanged + review 会显示“有新依据”；每条 insight 强制非空来源引用，无相关新闻也可能被模型附上无关候选。

## 变更

- 每张目标判断卡按相关新闻、当前情况与未知项、下一步排列。显示实际候选数量和筛选结果，区分相关与关联待核实；前三篇默认可见，其余随依据展开。汇总常显，原文引用、目标偏好与历史对照按需展开。
- 没有相关新闻时不附无关来源；上次情况另标“本轮未重新证实”。unchanged 显示本轮未确认实质变化，不再宣称有新依据。
- tracking-v2.5 要求先汇总产品/事件进展、当前阶段和未知条件，再提出最多一个有用核实方向。单纯新闻跟踪不默认引入购买任务或假定设备。
- 新版本校验把 insight 引用与 items 中的相关性、目标关联对齐。空引用仅在该目标没有相关或待核实候选时允许，必须 unknown + insufficient_evidence、无新增事实或改期；unchanged 不得含 material_change；no_change 不得同时更新或撤回。
- 历史记录按其原提示词契约校验，保存的关注、日程和决定不删除。新版本需重新检查；旧判断不冒充当前有效建议。
- 有界词法召回优先完整命中显式关注关键词，再按 BM25 排序；仍需 Agent 判断相关性，不能把关键词匹配当成事实确认。

## 交付与边界

已重新生成 `bundle/main.splash`、unsigned bundle 完整性与 `build/cfaw-news.zip`。摘要为模型对已有证据的归纳，结构校验不证明语义真实性；本轮未用真实 MiniMax 重放用户私有目标，测试案例不证明当前新闻网站的实际最新状态。来源、召回与正文片段仍有覆盖及长度限制，界面明确区分未知条件。使用新 bundle Review / Run 后重新检查关注，生成新流程的结果。
