# 关注动态与顶部天气修复

本次修改在 `cfaw-news-agent-10.11` 中完成。

- 关注动态仅使用普通新闻卡片，不再展示首页的今日精选、最新文章标题及快捷卡片；图片新闻不会被抽成精选轮播。
- 关注列表按启用的关注对象独立筛选，首页日程排序不再决定关注列表成员。当前有效的 Agent 判断按具体关注对象保留；同一对象已判无关不会通过关键词再次进入，尚未检查的另一对象仍可匹配。
- 日程判断不会覆盖同篇报道已确认的关注关联。关注卡片的 Agent 提示说明关注理由，未读数量使用同一筛选结果。
- 天气入口调整为 132 × 50，归零文字内边距并明确行距；城市单行省略，完整显示温度范围。品牌标题依据分配宽度调整字号，避免窄窗口下与天气相互挤占。
