# 关注新闻相关性与关联名称修复

修改目录：`cfaw-news-agent-10.11`。

## 已确认原因

实际存储中的“面向非程序员的 AI 会议纪要与演示文稿效率提升追踪”和“漫步者新品与产品动向跟踪”都包含 `tech` 分类召回规则。“张雪机车宣布拿下9月中大排量摩托车国内品牌销量第一”（IT之家，https://www.ithome.com/1/011/585.htm）被归为科技，但不在已保存分析轮次的候选证据或结果条目中。旧展示逻辑允许未经判断的分类候选直接进入关注列表，且卡片没有说明关联哪项关注，因此用户无法看出误匹配原因。

诊断只读取必要的新闻、关注和分析记录，没有启动用户宿主、调用真实模型或写入用户账户数据。

## 修改

- 关注动态只接受当前有效 Agent 判断确认关联启用关注的报道；分类、来源和关键词命中只产生候选。无关、不确定、未经判断及仅日程关联的报道不进入相关新闻列表，未读数使用同一筛选。
- 卡片与新闻详情显示具体关注名称，卡片保留简短 Agent 相关理由；同篇报道可以显示多个已确认关联的关注。不同关注的判断独立保留，日程分析不会覆盖已有关注关系。
- 候选数量单独显示，提供检查入口；恢复已有判断时说明正在恢复。新关注或旧判断失效时，空列表只说明尚无已确认报道，不声称关注对象没有实际进展。
- 英文关键词按 ASCII 词边界匹配，避免 `AI` 命中 `Daily`、`AirPods` 等词，保留 `AI助手` 等中英相邻写法。相同规则 ID 修改值后刷新匹配器，BM25 的完整关键词优先级使用相同边界；首页搜索保留原来的字面子串语义。
- 追踪提示词升级为 `tracking-v2.6`，要求具体品牌、产品或任务关联，不把分类或泛行业词当作相关性证明；证据不足以确认关系时返回 uncertain。同步新版证据标签展开、正文引用、目标判断与当前情况校验分支，保留历史契约。

## 使用与范围

重新 Review / Run `bundle`，再点击“检查关注更新”，生成新版当前结果。原关注、日程、历史与用户决定保留。每轮最多核对 8 条候选、2 个目标，不能把未覆盖候选当作已判断；当前并未增加完整候选遍历机制。首页浏览仍可独立于 AI 使用，相关新闻依赖模型确认，判断有误时仍需核对原始证据。
