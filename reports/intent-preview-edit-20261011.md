# 待确认理解的直接编辑

修改目录：`cfaw-news-agent-10.11`。

## 交互

“待确认的理解”新增“编辑理解”。新闻关注和目标关注都可以直接修改名称、目的、关注范围、偏好与限制，以及检索关键词；范围、偏好和关键词按每行一项填写。原有来源与分类扩展检索显示在编辑器中，可逐项移除。改变关注对象时提示同步调整关键词。

流程为：编辑理解 → 应用修改 → 核对预览 → 确认关注并保存。应用修改只更新本地草稿，不再请求模型、不创建正式关注；最终确认使用修改后的全部字段和检索规则。“放弃本次修改”返回进入编辑时的理解。“取消并保留草稿”保留未应用编辑，关闭或重开宿主后仍可继续。

名称为空、范围缺失、数量或字符超限时，编辑器显示具体校验提示，输入保留，原理解及正式关注不变。自动保存成功不会清除编辑器的校验提示。编辑时不提供最终确认或重新整理，存储入口也拒绝跳过应用修改直接确认。

## 数据与运行时边界

- 未完成内容存放于可选 `understanding_edit` 缓冲，原 `understanding` 仍保持有效；旧草稿没有该字段时继续兼容，不清理已有数据。
- 编辑与应用递增草稿版本，旧模型完成结果不能覆盖修改。应用／放弃先验证写入成功再切换状态，写入失败保留编辑。
- 修改已有关注仍沿用目标状态、版本与事务检查；转为新关注保留有效理解与编辑缓冲，避免丢失用户修改。
- 关键词重建全部 keyword 规则，来源与分类扩展规则显式显示，可删除；删除的规则不会在确认时恢复。
- 编辑区直接放在现有面板渲染回调中，输入控件匿名，避开宿主条件命名控件限制。原始范围文本使用 `scope_text`，应用后写入原 JSON 的 scope 字段，避开 Splash 保留字。
- 固定编辑字段使用显式成员更新，避免动态键赋值追加同名 JSON 字段而仍读取旧值。验证同时检查实际原生字段读取与磁盘 JSON 无重复成员。

## 使用

重新 Review / Run 本目录的 `bundle/`，在待确认理解中点击“编辑理解”，修改后先应用，再确认保存。原关注、日程、历史与用户决定保留；本次直接编辑针对新闻／目标关注，日程继续沿用原预览确认流程。
